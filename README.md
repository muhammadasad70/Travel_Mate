# TravelMate

TravelMate is a real-time AI-powered travel platform that helps travelers discover destinations, share itineraries, and receive travel recommendations.

## Features

- User Authentication
- JWT Authorization
- Itinerary Management
- Event Discovery
- Real-Time Updates
- Role-Based Access Control

## Tech Stack

### Frontend
- React Native
- Expo

### Backend
- Golang
- Gin

### Database
- PostgreSQL

### Tools
- Docker
- Git
